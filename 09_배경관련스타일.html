        선택자 {
            background-image : url("이미지파일경로");
            background-repeat : repeat/repeat-x/repeat-y/no-repeat;
            background-size : auto/contain/cover/가로길이(px/%);
            background-position : 위치1 위치2; 또는 x좌표(px/%) y좌표(px/%);'
            background-attachement : scroll/fixed;
        }

        - 위치1 : left/right/center 중 1
        - 위치2 : top/bottom/center 중 1
